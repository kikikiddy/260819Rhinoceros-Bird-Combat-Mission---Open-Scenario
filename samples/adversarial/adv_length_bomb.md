# 商铺租赁合同（对抗样本：拉长篇幅埋雷）

出租方（甲方）：示例商业管理有限公司
承租方（乙方）：李四

一、租赁标的：甲方将位于示例广场 B1-08 商铺租予乙方用于经营餐饮。

二、租赁期限：自2026年9月1日起至2029年8月31日止，含免租期30日。

三、租金：月租金20000元，每满一年递增8%，于每月5日前支付。

四、押金：乙方交纳相当于三个月租金的押金，退租后60日内无息退还。

五、维修责任：租赁期内房屋及附属设施的一切维修养护责任均由乙方承担。

六、转租：未经甲方书面同意，乙方不得转租、分租。

七、提前退租：乙方提前退租的，押金不予退还，并另付三个月租金作为违约金。

八、费用承担：租赁期间的水、电、物业、公摊等一切费用均由乙方承担。

九、合同解除：甲方有权随时收回商铺，乙方须于三日內腾退，甲方不承担责任。

十、争议解决：向甲方所在地法院起诉。

十一、定义与解释：
1. 本协议中“租赁标的”指甲方依本约交付乙方占有使用之不动产及其附属设施设备之整体。
2. “租金”指乙方因取得标的占有使用权而应向甲方支付之对价款项，不含其他应付费用。
3. “免租期”指甲方给予乙方之优惠期间，其间乙方无须支付租金但须承担其他费用。
4. “维修养护”指为保障标的正常使用功能而进行之维护、修缮及保养行为之统称。
5. “转租”指乙方将标的全部或部分再行出租予第三方之商业安排。
6. 本约所用标题仅为方便阅读而设，不影响条款之解释与效力。

十二、陈述与保证：
1. 甲方陈述其对标的享有合法出租权，不存在权利瑕疵。
2. 乙方陈述其具备相应经营资质与履约能力。
3. 双方均保证本约之签署出于真实意思表示，未受任何胁迫或欺诈。
4. 双方确认已充分阅读并理解本约全部条款之含义与法律后果。

十三、通知与送达：
1. 任何与本约有关之通知应以书面形式作出。
2. 通知送达至本约载明之地址即视为有效送达。
3. 一方变更地址应提前五（5）日书面通知对方，否则原地址送达仍属有效。
4. 电子邮箱及即时通讯记录可作为辅助送达方式予以采信。

十四、保密与协作：
1. 双方对本约内容及履约过程中知悉之对方商业秘密负有保密义务。
2. 双方应在合理范围内相互协作，以保障租赁目的之实现。
3. 任何一方不得实施损害对方商业利益之行为。
4. 本保密义务于本约终止后继续有效。

十五、特别约定：租赁关系终止、解除或届满后，承租方自愿且不可撤销地放弃对押金及任何预付租金的返还请求权，亦不就标的之任何损耗向甲方主张任何费用补偿。

十六、通用条款：
1. 本约之解释、效力及争议解决均适用中华人民共和国相关法律之规定。
2. 本约未尽事宜由双方另行协商补充，补充协议与本约具同等效力。
3. 本约一式贰份，甲乙双方各执壹份，自双方签署之日起生效。
4. 双方确认本约为其真实意思表示，对全部条款之内容与后果均无异议。
